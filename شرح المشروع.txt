# مكتبات مشروع نظام إدارة الموظفين

## المكتبات التي تم استخدامها في المشروع

تم اختيار مجموعة من المكتبات البسيطة والمناسبة لطبيعة المشروع، وذلك لتوفير Authentication وتصميم الواجهات وإضافة الأيقونات وإنشاء تقارير PDF، مع الحفاظ على المشروع بسيطًا وسريع التنفيذ.

---

# 1. Laravel UI

اسم المكتبة:

laravel/ui

الإصدار المستخدم:

v4.6.3

أمر التثبيت:

composer require laravel/ui

وظيفة المكتبة:

تم استخدام Laravel UI لتجهيز نظام تسجيل الدخول والمصادقة Authentication داخل المشروع، مع الاعتماد على Blade وBootstrap بدل استخدام Vue أو React.

ستساعد المكتبة في تجهيز صفحات ووظائف المصادقة مثل:

- Login
- Register
- Logout
- Forgot Password
- Reset Password

كما توفر Scaffold جاهزًا يمكننا البناء عليه بدل إنشاء نظام تسجيل الدخول من الصفر.

بعد تثبيت المكتبة سيتم تنفيذ الأمر:

php artisan ui bootstrap --auth

وظيفة هذا الأمر:

يقوم بتجهيز Authentication Scaffolding باستخدام Bootstrap، وإنشاء الملفات والواجهات المطلوبة لتسجيل الدخول والتسجيل والمصادقة.

مهم:

Laravel UI مسؤولة عن Authentication والواجهة الأساسية للمصادقة فقط، وليست مسؤولة عن إدارة الموظفين أو الأقسام.

---

# 2. Bootstrap

اسم المكتبة:

bootstrap

أمر التثبيت:

npm install bootstrap @popperjs/core

وظيفة المكتبة:

تم استخدام Bootstrap لتصميم جميع واجهات النظام.

بدل كتابة CSS من الصفر لكل عنصر، سنستخدم مكونات Bootstrap الجاهزة لبناء واجهة النظام بسرعة.

سيتم استخدام Bootstrap في:

- Dashboard
- Employee Pages
- Department Pages
- Forms
- Tables
- Buttons
- Cards
- Alerts
- Navigation Bar
- Modals
- Responsive Layout

وبالتالي سيكون تصميم النظام مبنيًا على Bootstrap مع استخدام Blade لعرض الصفحات.

---

# 3. @popperjs/core

اسم المكتبة:

@popperjs/core

أمر التثبيت:

npm install bootstrap @popperjs/core

وظيفة المكتبة:

هذه مكتبة مساعدة لبعض مكونات Bootstrap التي تحتاج إلى تحديد موقع العناصر بشكل ديناميكي.

تستخدم خصوصًا مع مكونات مثل:

- Dropdown
- Tooltip
- Popover

ولا يتم التعامل معها عادةً بشكل مباشر داخل صفحات المشروع، وإنما يحتاج إليها Bootstrap لتشغيل بعض مكوناته بشكل صحيح.

---

# 4. Bootstrap Icons

اسم المكتبة:

bootstrap-icons

أمر التثبيت:

npm install bootstrap-icons

وظيفة المكتبة:

توفر مجموعة كبيرة من الأيقونات الجاهزة التي سيتم استخدامها داخل واجهة النظام.

سيتم استخدامها في أماكن مختلفة مثل:

- أيقونة Dashboard
- أيقونة الموظفين
- أيقونة الأقسام
- أيقونة التقارير
- أيقونة الإضافة
- أيقونة التعديل
- أيقونة الحذف
- أيقونة البحث
- أيقونة العرض
- أيقونة تسجيل الخروج

الهدف منها تحسين شكل الواجهة وتوضيح وظيفة الأزرار والعناصر للمستخدم.

---

# 5. DomPDF

اسم المكتبة:

barryvdh/laravel-dompdf

الحالة:

سيتم تثبيتها لاحقًا عند البدء في تنفيذ قسم التقارير.

أمر التثبيت:

composer require barryvdh/laravel-dompdf

وظيفة المكتبة:

سيتم استخدام DomPDF لإنشاء ملفات PDF من صفحات Blade.

أي أننا سنقوم بإنشاء View خاصة بالتقرير، ثم تقوم المكتبة بتحويلها إلى ملف PDF يمكن للمستخدم فتحه أو طباعته.

التقارير التي سيتم إنشاؤها باستخدامها:

1. تقرير جميع الموظفين.

2. تقرير موظف محدد.

3. تقرير الموظفين حسب القسم.

4. تقرير الموظفين النشطين.

5. تقرير إحصائيات الموظفين.

مثال على طريقة العمل:

Blade View
    ↓
DomPDF
    ↓
PDF File

# ملخص المكتبات

المكتبات المستخدمة أو التي سيتم استخدامها في المشروع:

1. laravel/ui

الغرض:
Authentication وتجهيز واجهات تسجيل الدخول باستخدام Bootstrap وBlade.

2. bootstrap

الغرض:
تصميم واجهات النظام والجداول والنماذج والأزرار والبطاقات وغيرها.

3. @popperjs/core

الغرض:
دعم بعض مكونات Bootstrap التي تحتاج إلى تحديد مواقع العناصر مثل Dropdown وTooltip.

4. bootstrap-icons

الغرض:
إضافة الأيقونات إلى واجهة النظام.

5. barryvdh/laravel-dompdf

الغرض:
إنشاء تقارير PDF من صفحات Blade.

---

# أوامر تثبيت المكتبات

تم تنفيذ الأوامر التالية:

composer require laravel/ui --prefer-source

npm install bootstrap @popperjs/core

npm install bootstrap-icons

وسيتم لاحقًا تنفيذ:

composer require barryvdh/laravel-dompdf

ثم بعد تثبيت Laravel UI سيتم تنفيذ:

php artisan ui bootstrap --auth

وبعد تجهيز ملفات الواجهة سيتم استخدام:

npm install

npm run build

# سبب اختيار هذه المكتبات

تم اختيار هذه المكتبات لأن المشروع مطلوب أن يكون بسيطًا وسريع التنفيذ، ولا يحتاج إلى استخدام تقنيات Frontend معقدة.

لذلك تم الاعتماد على:

Laravel UI
    ↓
Authentication

Bootstrap
    ↓
تصميم الواجهات

Bootstrap Icons
    ↓
الأيقونات

@popperjs/core
    ↓
دعم مكونات Bootstrap

DomPDF
    ↓
تقارير PDF

وسيتم بناء جميع صفحات المشروع باستخدام Blade، بدون استخدام Vue أو React.

# الحالة الحالية

تم الانتهاء من تثبيت:

- laravel/ui
- bootstrap
- @popperjs/core
- bootstrap-icons

وتم تجهيز المشروع لاستخدام Bootstrap وLaravel UI.

المكتبة الخاصة بتقارير PDF لم يتم تثبيتها حتى الآن، وسيتم تثبيتها عند الوصول إلى مرحلة التقارير.

الخطوة التالية هي تنفيذ:

php artisan ui bootstrap --auth

وبعدها سيتم البدء في بناء Authentication ثم الانتقال إلى أقسام المشروع الأخرى.
